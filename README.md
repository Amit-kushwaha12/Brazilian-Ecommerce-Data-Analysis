# Brazilian E-Commerce Data Analysis | SQL & Power BI

## Project Overview

This project focuses on analyzing Brazilian E-Commerce public dataset (Olist) to understand business performance, customer behavior, sales trends, and delivery operations.

The objective is to transform raw e-commerce data into meaningful business insights using SQL and Power BI.

## Tools & Technologies

- **SQL:** PostgreSQL
- **Data Visualization:** Power BI
- **Data Analysis:** Data Cleaning, Data Exploration, KPI Analysis
- **DAX:** Measures and Calculated Metrics
- **Database:** PostgreSQL

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist.

Dataset source: [Brazilian E-Commerce Public Dataset – Olist (Kaggle)](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The dataset contains information about:

- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product Categories

**Note:** Raw CSV files are not included in this GitHub repository. Download the dataset from Kaggle and place the CSV files inside the `dataset` folder before running the SQL scripts.

## How to Use This Project

1. Clone this repository.
2. Download the Olist dataset from Kaggle.
3. Place the CSV files inside the `dataset` folder.
4. Import the data into PostgreSQL.
5. Execute the SQL scripts.
6. Open the Power BI file from the `powerbi` folder.
7. Refresh the dataset after configuring the data source.
